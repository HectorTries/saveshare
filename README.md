# DebtCrush 🎯 (served at hectortries.github.io/saveshare)

Gamified micro-payment slingshot arcade for debt payoff.

**This repo is the GH Pages deployment target.** The canonical source lives in
[HectorTries/Binx-Debt-Pay-Off-](https://github.com/HectorTries/Binx-Debt-Pay-Off-).

To redeploy (from the source repo):

```bash
npm run build -- --base=./
# then copy dist/* here, commit, push to master
# or run scripts/deploy.sh from the source repo
```
